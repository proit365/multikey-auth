# Changelog

## 1.0.0-development

- Published MKAP v1 protocol specification and deterministic vectors.
- Added framework-independent PHP cryptographic core.
- Added key generation, lifecycle, AES-GCM storage, exports, and PDO/mysqli
  repositories.
- Added framework-independent challenge issuer and atomic-consumption verifier.
- Added PHP, Laravel, JavaScript/Node, and Flutter client implementations.
- Added Laravel server adapter and standalone administrative CLI.
- Added SQLite/MySQL migrations, interoperability matrix, threat model,
  security review addendum, known limitations, and local performance benchmark.

No release is claimed as production-ready or independently security reviewed.

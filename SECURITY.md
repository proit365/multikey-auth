# Security

MKAP is a custom authentication protocol and has not received an independent
security audit. Do not use it for production authorization until that review
is completed and the documented limitations are resolved.

No independent security review has been completed. Internal planning or
automated review documents are not an independent audit.

Report suspected vulnerabilities privately to the repository maintainer.
Do not include secret keys, master keys, exports, or live credentials in
issues or reports.

See [THREAT_MODEL.md](THREAT_MODEL.md) and
[KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).
